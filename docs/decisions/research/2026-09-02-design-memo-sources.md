# Design memo 2026-09-02 — verified research sources

Every entry below was URL-fetched and checked against its source page by a skeptic agent on 2026-09-02, in four sweeps
(agent playtesting · AI-built games · procedural CRPG towns · LLM-DM evaluation). Only items the skeptic marked
`VERIFIED` are listed; two `WEAK` items were dropped and are not cited by the memo. Companion to
[`../DESIGN-MEMO-2026-09-02.md`](../DESIGN-MEMO-2026-09-02.md).

## 1. Agent playtesting / automated game QA

- **TITAN** — LLM agent for MMORPG testing (state abstraction · action prioritization · action-trace memory with reflective self-correction · LLM oracles); ~95% task completion, four previously unknown bugs, eight real-world game QA pipelines. Oracles are scoped to functional/logic bugs, not visual. <https://arxiv.org/abs/2509.22170>
- **GBQA** — 30 generated games, 124 human-verified injected bugs, three difficulty tiers; best model (Claude-4.6-Opus, thinking) detects only 48.39%. Runtime discovery is harder than code generation. <https://arxiv.org/abs/2604.02648>
- **VLM clipping detection** — six VLMs × four prompt variants on auto-labelled frames; Gemini-3.1-Flash most accurate and most prompt-robust; significant FALSE POSITIVES on near-contact geometry and partial occlusion; VLMs work best as high-recall candidate filters in a multi-stage pipeline. <https://arxiv.org/abs/2607.25921>
- **Human-AI collaborative game testing** — 800 test cases, 276 participants, four conditions; VLM assistance significantly improves defect identification (most for testers with detailed defect knowledge), but AI errors degrade human decisions — mitigation must be explicit. <https://arxiv.org/abs/2501.11782>
- **VideoGlitchBench / GliDe** — 5,238 gameplay videos from 120 games with glitch descriptions and precise temporal spans; game-aware memory + debate reflector + event grounding beats plain multimodal baselines. <https://arxiv.org/abs/2604.07818>
- **Bug frame retrieval** — FFmpeg keyframes + GPT-4o ranking cut videos to a median 1.90% of frames while preserving bug visibility in 98.79% of cases; F1 0.79 / top-1 accuracy 0.89; Lighting & Shadow F1 0.94, Physics & Collision 0.86, Animation & VFX 0.51. <https://arxiv.org/abs/2508.04895>
- **SMART** — LLM reads AST-level diffs to extract functional intent, feeding a hybrid RL reward; >94% branch coverage of modified code at 98% task completion (Overcooked, Minecraft), ~2× plain RL's branch coverage. <https://arxiv.org/abs/2512.12706>
- **SIMA 2** — Gemini-powered generalist agent playing 3D worlds from screen pixels with virtual keyboard/mouse; self-improves from Gemini-proposed tasks with no human gameplay data. Limits: long-horizon tasks, limited context memory, imprecise low-level actions, incomplete 3D scene understanding. <https://deepmind.google/blog/sima-2-an-agent-that-plays-reasons-and-learns-with-you-in-virtual-3d-worlds/>
- **modl.ai** — black-box bot QA with no SDK or engine hooks; build + plain-language test definitions; covers visual glitches, missing assets, perf drops, logic bugs, crashes, softlocks, broken menus; auto-files reports with screenshot/video/log evidence and an AI severity score. Best on structured-UI titles, not timing-critical gameplay. <https://modl.ai/>
- **MeepleLM** — virtual playtester inferring dynamics from written rules with no engine, modelling heterogeneous player archetypes; MDA reasoning over 1,727 rulebooks and ~150,000 reviews; 70% preference in a user study (ACL 2026). <https://arxiv.org/abs/2601.07251>
- **Lost in Simulation** — agent success rates vary up to 9 percentage points purely by WHICH LLM simulates the user; simulated evaluations underestimate hard tasks and overestimate moderate ones; worse outcomes for AAVE speakers. <https://arxiv.org/abs/2601.17087>
- **HTML5 canvas visual bugs** — 80 bug-injected + 20 clean screenshots across 20 applications (Layout / Rendering / Appearance / State); supplying a README, bug-type descriptions and a bug-free REFERENCE screenshot raises detection to up to 100% per-application accuracy without a precise visual oracle. <https://arxiv.org/abs/2501.09236>

## 2. AI-built games — what agents can and cannot finish

- **GameCraft-Bench** — 140 Godot end-to-end tasks across 15 game families with interaction-grounded rubric judging; best agent 41.46%, most below 40%; agents "often implement recognizable mechanics" but fail at complete games with sufficient content, functional visual feedback and coherent presentation. <https://arxiv.org/abs/2606.17861>
- **PlaytestArena / Play2Code** — 200 browser games; direct generation 29.7-31.6% rubric pass; Play2Code 66.8% (+37.1 over direct, +14.6 over agentic-without-playtest); code inspection alone 52.2% vs 66.8% with play; monotonic gains over five rounds; GUI-human agreement 84.2%, κ 0.64 vs human-human 0.66. <https://arxiv.org/html/2605.28258v1>
- **Self-authored verification gap** — 35 model-game experiments (5 Atari games × 7 models, 10 rounds); ALL 35 end with a self-score ≥ 0.70, yet 15 of 35 score below the game's random-play reference. The authors name this the verifier-deployment gap. <https://arxiv.org/html/2607.24300v1>
- **Coding-agent failure forms** — 20,574 sessions across 1,639 repos; seven recurring failure forms including action-bounding and progress reporting; 90.50% of episodes cost effort/trust rather than irreversible damage; 91.49% of visible resolutions need explicit user correction; constraint violations and inaccurate self-reporting grow as a share over time. <https://arxiv.org/abs/2605.29442>
- **Static vs agentic game master** — v1 plain prompt engineering vs v2 multi-agent ReAct for a solo RPG; v2 preserved playability while improving modularity and measured game experience, specifically immersion and curiosity. <https://arxiv.org/abs/2502.19519>
- **Stray Spark (48-agent studio, third-party analysis)** — hierarchy of studio director / 5-7 department leads / 30-40 specialists produced concept docs, GDD outlines, scaffolded Unreal projects, shader code, dialogue trees, level blockouts. Scaffolding and cross-system consistency worked; failures are out-of-distribution problems, game-feel parameter values, and judgments that require having PLAYED it. <https://www.strayspark.studio/blog/claude-code-multi-agent-studios-game-development>
- **Spell Cascade v0.8.3 (5-agent studio)** — 9 of 17 tasks in one session; `blockedBy` dependencies stopped the shipper publishing before screenshots existed; explicit do-not-touch file ownership prevented conflicts; cross-agent invalidation forced asset regeneration (mitigated with Xvfb capture); author would not trust an AI designer for game feel, UI or UX. <https://dev.to/yurukusa/i-ran-a-5-agent-game-studio-with-claude-code-teams-2lpk>
- **Gloomstep Dungeon** — single-dev Claude-Code browser roguelike in seven phases, each ending playable; the agent inferred 37 monster identities and depth-appropriate stats from sprite FILENAMES alone but never wired the sprites in, leaving placeholder characters; the human made every architectural decision. <https://barretblake.dev/posts/development/2026/03/ai-roguelike/>

## 3. Procedural generation — dungeons, towns, benchmarks

- **Unexplored's generator** — three-phase pipeline (abstract graph layout → abstraction resolution with biomes and Obstacle/Lock/Key non-terminals → spatial conversion); ~5,000 find-replace rules across ~50 PhantomGrammar modules; 5×5 node grid, one of 24 major cycle types, graph doubled then expanded 5× into a tilemap with cellular automata and pattern-matched set pieces; key/lock consistency via a special key→lock edge. <https://www.boristhebrave.com/2021/04/10/dungeon-generation-in-unexplored/>
- **Cyclic dungeon generation (Dormans)** — loops replace branching mission trees: two arcs between start and goal, named patterns (risk/reward asymmetry, lock-then-detour-for-key, nested cycles); the mission graph holds structural relationships but not positions; translated into a low-resolution tilemap whose resolution is raised before puzzle elements are placed. <https://www.gamedeveloper.com/design/unexplored-s-secret-cyclic-dungeon-generation->
- **Graph rewriting for levels** — find-and-replace over graphs; rules can re-apply to their own output. Shipped tools restrict it: Dungeon Architect supports complex patterns but no loops; Enter the Gungeon typically matches only single rooms. <https://www.boristhebrave.com/2021/04/02/graph-rewriting/>
- **Unexplored 2 — tiles to curves** — Voronoi seeded one point per tile, corner detection between ground types, seed displacement, curved decorative assets along type-change edges; artificial structures exempt from displacement. NOT marching squares — the tessellation itself is deformed. <https://www.gamedeveloper.com/design/unexplored-2-dev-blog-tiles-to-curves>
- **Caves of Qud village generation (GDC 2019)** — end-to-end walk-through generating histories, cultures, architectural styles, storytelling traditions, NPCs and quests together, framed around linking systems across tiers of granularity. <https://www.gdcvault.com/play/1026313/Math-for-Game-Developers-End>
- **Caves of Qud is deliberately hybrid** — towns largely static/pre-designed; dungeons, wilderness, history and lore generated per run. Bucklew traces it to Omega and ADOM — "static areas wrapped in procedural worlds" — to keep a static backbone for deep worldbuilding. <https://www.gamedeveloper.com/design/tapping-into-the-potential-of-procedural-generation-in-caves-of-qud>
- **WFC as an MDP** — an external optimizer pursues objectives while WFC propagation enforces adjacency constraints; joint optimization of constraints AND objectives "consistently underperforms" optimizing over the WFC-MDP, degrading further as task complexity rises. <https://arxiv.org/abs/2509.09919>
- **GDMC settlement-generation competition** — eighth iteration (2025, Minecraft 1.21.4, results at IEEE CoG Aug 2025), scored on four human-judged axes: Adaptation to Environment and Terrain, Functionality from an Embodied Perspective, Narrative Integration, Visual Aesthetics, plus an opt-in "Best Chronicle" award. <https://gendesignmc.wikidot.com/wiki:2025-settlement-generation-competition>
- **Sturgeon (crowdgames)** — tile levels, graphs and playthroughs; Sturgeon-MKIV (AIIDE 2024) generalises tile rewrite rules to rewrites on node/edge labels of subgraphs, solving the level graph and a valid playthrough simultaneously; 2025 work adds softlock-free generation and a constraint-based graph grammar unifying level and playthrough generation. <https://github.com/crowdgames/sturgeon-pub>
- **Narrative-to-Scene (AIIDE 2025 EXAG)** — story text → three key time frames → Object-Relation-Object spatial triples → GameTileNet affordance-aware retrieval → placement via cellular-automata terrain plus predicate-derived spatial rules; evaluated on tile-object matching, affordance alignment and spatial-constraint satisfaction over ten narratives. <https://arxiv.org/abs/2509.04481>
- **The PCG Benchmark** — 12 content-generation problems with variants scored on quality, diversity and controllability; baseline random / ES / GA runs show difficulty varies sharply with the chosen optimization objective. <https://arxiv.org/abs/2503.21474>

## 4. LLM dungeon-master evaluation and drift

- **CoC-Seduce** — 5,376-sample adversarial TRPG benchmark over 20 models; 9.58% average FALSE-PASS rate, 17.30% pseudo-logic; GPT-5.4 18.17% vs GPT-5 14.34%; setting matters — 1920s Urban 0% vs Ancient China 11.88%. <https://arxiv.org/html/2607.02802v1>
- **NCP-Bench** — 100 environments with a reference trajectory, commitment set and FACT LEDGER; an auditor runs up to 100 turns over three violation classes; GPT-5.2 42% survival after 20 turns; fact conflicts 40-68%; DeepSeek-V3.2 15.40% trajectory progress; Kimi-K2.5 lasts 2.88 turns. <https://arxiv.org/html/2608.08160>
- **RPGBench** — LLMs as text RPG engines via Game Creation and Game Simulation, splitting objective machine-checkable metrics from LLM-as-judge subjective metrics; SOTA models write engaging stories but fail at consistent verifiable mechanics. <https://arxiv.org/abs/2502.00595>
- **Static vs multi-agent game master (controlled)** — v2 ReAct maintained continuity while improving modularity, immersion and curiosity; player experience measured across ease of control, goals and rules, progress feedback and meaning. <https://arxiv.org/abs/2502.19519>
- **Hidden Door design review (Aug 2025 launch)** — no underlying world state, divergent realities per choice, free text regenerating choices instead of acting, instantly-resolving objectives, NPC harm instantly forgiven, a sprawling intro chapter. <https://ianbicking.org/blog/2025/08/hidden-door-design-review-llm-driven-game.html>
- **Agency as Player Influence + Intention Following (ACL 2025)** — both improved via Playwriting-guided Generation and Plot-based Reflection, validated by human judgment. <https://arxiv.org/abs/2502.17878>
- **TextQuests** — LLM agents on Infocom interactive fiction with no external tools, scoring progress AND harm; reports long-context degradation and variation with reasoning budget. <https://arxiv.org/pdf/2507.23701>
- **clembench — dialogue games as a third paradigm** — distinct from static test sets and arena preference voting; objective reproducible scoring free of inter-rater variance while exercising multi-turn state tracking. <https://arxiv.org/pdf/2507.08491>
- **"Beyond the Mean" — Reliable Change Index for LLM evaluation** — establish a within-model variance baseline from REPEATED runs, then require a delta to exceed that threshold before calling a version change an improvement or a regression. <https://arxiv.org/pdf/2604.27405>
- **CFSM / CPFSM** — an LLM codifies a textual character profile into an interpretable FSM of states and transitions (CPFSM adds probabilistic transitions), beating prompt-only baselines on structured evaluation and open-ended role-play. <https://arxiv.org/abs/2602.05905>
- **Friends & Fables patch 25.44** — narration model switching (Finch vs Fenix); Fenix reported better at instruction following and extra context and 2×+ more expensive. Evidence is Discord user testimony with NO disclosed methodology — treat as anecdote, not measurement. <https://fables.gg/patch-notes/patch-notes-2545-fenix-model-switching-pricing-update>
