WorldOS — renderer-as-thin-client (Phaser 3, M0)

A renderer that owns no game state: it reads /atlas-surface, /combat-surface, /character-surface, /events and writes only an intent via POST /move. Tokens are placed by engine zone (zone bands, not a VTT grid), re-derived client-side — the renderer owns layout, the engine owns truth. Runs standalone on bundled fixtures; add ?campaign=<id> (optional ?base=http://127.0.0.1:8765) to drive a live game.

Served at /openworlds/render/ by viewer/server.py (no server change — the OpenWorlds asset handler serves any file under viewer/openworlds/). Consumes the M0 render-profile contract (docs/roadmap/contracts/render-profile.md). See README.md for the contract this validates.
