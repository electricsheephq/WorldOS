# Contributing to WorldOS

Thanks for helping improve WorldOS.

WorldOS uses a custom source-available commercial EULA, not an OSI open-source
license. Contributions are accepted only under the WorldOS Contributor License
Agreement in `CLA.md` unless ElectricSheep agrees otherwise in writing.

## Contribution Rules

- Read `LICENSE`, `ROYALTY-ADDENDUM.md`, `COMMERCIAL-LICENSE.md`, `CLA.md`,
  and `THIRD_PARTY_NOTICES.md` before submitting a pull request.
- Do not submit confidential information, customer data, private imported
  content, copyrighted adventure text, proprietary setting material, or assets
  You are not authorized to contribute.
- Do not remove third-party attribution or license notices.
- Keep fan-content and separately licensed material under the per-world license
  and attribution rules already used in `content/worlds/`.
- Keep code and docs changes focused so licensing and attribution are easy to
  review.

## CLA Requirement

By opening a pull request, You acknowledge that Your contribution is submitted
under `CLA.md`. ElectricSheep may require a separately signed individual or
entity CLA before merging non-trivial contributions.

## Pull Request Checklist

- The pull request describes what changed and why.
- The CLA acknowledgement in the pull request template is checked.
- Any third-party material is identified with source and license.
- `python3 scripts/license_check.py` passes for licensing/content changes.
