WorldOS M0 spike — renderer-as-thin-client (Phaser 3)

Proves the architecture decision live: a Phaser renderer that owns no game state — it reads /atlas-surface, /combat-surface, /character-surface and writes only an intent via POST /move. Tokens are placed by engine zone (zone bands, not a VTT grid), re-derived client-side to prove the renderer owns layout. Runs standalone on bundled fixtures; add ?campaign=<id> (and optional ?base=http://127.0.0.1:8765) to point at a live viewer.

Serve locally: python3 -m http.server from this dir, open /index.html. See README.md for what it validates + the contract gaps it surfaces.
